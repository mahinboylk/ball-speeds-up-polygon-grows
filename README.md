# Ball Speeds Up, Polygon Grows

A collection of AI-generated bouncing ball simulations — each file is a different AI's take on the same prompt:

> *A ball bouncing inside a polygon. Every bounce speeds the ball up and adds a side to the polygon.*

## AI Versions

| File | AI Model |
|------|----------|
| `ChatGPT.html` | OpenAI ChatGPT |
| `Claude.html` | Anthropic Claude |
| `Gemini.html` | Google Gemini |
| `Grok.html` | xAI Grok |
| `Kimi.html` | Moonshot Kimi |
| `MiMo.html` | Xiaomi MiMo |
| `Qwen.html` | Alibaba Qwen |

## How to Run

Open any `.html` file in your browser — no server or dependencies needed.

## What You'll See

- A ball bouncing inside a polygon on a dark canvas
- Each bounce increases the ball's speed
- Each bounce adds one more side to the polygon (triangle → square → pentagon → ...)
- Watch how each AI interprets the physics, visuals, and animation differently
